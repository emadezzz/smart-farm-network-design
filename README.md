# Smart Farm Network Design

Smart farm network simulation developed using Cisco Packet Tracer to support office systems, retail operations, IoT devices and security infrastructure.

## Overview

This project was developed for the Computer Networks module.

The objective was to design and simulate a scalable smart farming network capable of supporting multiple operational areas while maintaining security, reliability and efficient traffic management.

The design uses VLAN segmentation, inter VLAN routing and IoT integration to create an organised and realistic network environment.

---

## Features

- Smart farm network simulation
- Cisco Packet Tracer implementation
- Router on a Stick configuration
- VLAN segmentation
- Inter VLAN routing
- Wireless access points
- IoT integration
- Security camera network
- Hierarchical network design
- Connectivity verification and testing

---

## Network Architecture

The design follows a hierarchical structure:

- One central router
- One core switch
- Four distribution switches
- Office network
- Shop systems
- PYO kiosk
- Greenhouse IoT devices
- Security camera systems
